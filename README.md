# Bug 猎人

> 你不能改它的代码，只能写测试让它现形。

一个命令行小游戏：每一关给你一段「能正常运行」的代码，里面藏着一个 bug。
你无法修改它，只能写 pytest 测试，让那个 bug 暴露出来。

## 怎么算过关

两个条件**同时**满足才算：

1. 你的测试在**有 bug 的版本**上失败
2. 同一个测试在**正确版本**上全部通过

只满足第一条，说明你的测试会误报——`assert False` 也能让它失败。
只满足第二条，说明你的测试什么也没测。

这个设计训练的不是「怀疑一切」，是「精准」。

## 安装

```bash
pip install bug-hunter
```

## 开始

```bash
bug-hunter list
bug-hunter play 001-off-by-one
```

## 已知限制

- 关卡代码对玩家可读，理论上可以针对代码内容作弊。不打算防——作弊损害的是你自己。
- 目前只支持 pytest。
- 判题在本地执行，不做沙箱隔离（跑的是你自己的代码，风险归你）。
